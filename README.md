### ☕ About Groove

**Groove** is a tactile, relaxing, high-fidelity vinyl record console built to run interactive web applications as physical album releases.

Instead of plain links or generic grid cards, **Groove** lets you flip through illustrated record sleeves inside a wooden crate, place records onto a spinning turntable platter, drop the mechanical tonearm, and experience sandboxed web modules with full Web Audio API synthesis.

### ✨ Features & Aesthetic System

- 📦 **Wooden Crate Rack**: Swipe & flip through illustrated album sleeves with custom theme gradients.
- 💿 **Top-Down Vinyl Player**: Rotating vinyl center labels, realistic groove texturing, and animated tonearm play positioning.
- 🔊 **Web Audio Synthesizer**: Procedural vinyl scratches, tactile click feedback, card hover harmonics, and background atmospheric soundscapes.
- 📓 **Registry Liner Notes Booklet**: Place the special `LP // GUEST` record on the platter to open a live guestbook registry booklet.
- 💻 **Live Code Sandbox & Inspector**: Split-screen live code editor inside the vinyl preview overlay for on-the-fly tweaking.
- 🌌 **Dynamic Particle Systems**: Ambient particle effects (falling rain, sparkles, laser grids) tailored to each album's mood.

### 🛠️ Getting Started

```bash
# 1. Clone the repository
git clone https://github.com/nandinigoyaldev/Groove.git

# 2. Navigate into directory
cd Groove

# 3. Install dependencies
npm install

# 4. Start local dev server
npm run dev

# 5. Build for production
npm run build
```
